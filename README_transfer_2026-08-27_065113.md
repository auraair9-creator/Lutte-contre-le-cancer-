# LUTTE CONTRE LE CANCER — mini campagne de dons

## 1. Personnaliser
Ouvrez `script.js` et remplacez :
`const DONATION_NUMBER = "À REMPLACER";`
par le numéro Mobile Money destiné aux dons.

## 2. Publier gratuitement
Vous pouvez mettre ces fichiers sur GitHub Pages, Netlify ou Vercel.
Après publication, remplacez le lien contenu dans `QR_CODE.png` si vous utilisez une autre adresse.

## 3. Important pour le paiement
Cette version ne demande jamais de PIN et ne simule pas un paiement.
Pour un véritable paiement "un clic", il faut une intégration officielle et sécurisée d'un prestataire de paiement (Orange Money / MTN MoMo, selon le pays et le compte disponible), avec un serveur backend.

## 4. QR code
`QR_CODE.png` est un exemple qui pointe vers :
https://YOUR-USERNAME.github.io/lutte-contre-le-cancer/

Après publication, générez un nouveau QR code avec l'adresse réelle du site.
